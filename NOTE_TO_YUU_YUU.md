# NOTE TO YUU YUU

Welcome.

This project is split into two main parts:

## 1. Frontend
- Folder: `frontend/`
- This is what users see and interact with
- Includes:
  - HTML
  - CSS
  - JavaScript

## 2. Backend
- Folder: `backend/`
- This is where your chatbot logic lives
- Handles:
  - AI responses
  - API routes
  - Data processing

## How they work together
- The frontend sends messages to the backend
- The backend processes the message and sends a response back

## Your goal
- Build the UI in `frontend/`
- Build the chatbot logic in `backend/`
- Connect them together

## Important
Do not mix frontend and backend code in the same folder.

Keep things organized from the start.
